# ⚖️ LegalEase

## AI-Powered Legal Document Generator

LegalEase is a Generative AI application that creates editable legal-document drafts from structured user input.

## Technology Stack

- Python
- Streamlit
- FastAPI
- Gemini API
- Google GenAI SDK
- Pydantic
- python-docx
- FPDF2
- Requests

## Architecture

User
↓
Streamlit
↓
FastAPI
↓
Gemini
↓
Generated Legal Draft
↓
Preview / Edit
↓
TXT / DOCX / PDF

## Supported Documents

- Employment Contract
- Non-Disclosure Agreement
- Lease Agreement
- Service Agreement
- Freelance Work Contract
- Employment Offer Letter
- General Agreement
- Custom Legal Document
